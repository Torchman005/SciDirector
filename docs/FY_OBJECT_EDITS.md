# fy 单镜对象与精确修订

日期：2026-11-10。对应 DrawAI 参考方案的第一阶段，不安装 DrawAI 插件、不替换 fy、不增加另一套任务状态机。

## 数据与绘制

主编码器现在输出 `palette`、`document`、`code`、`explanation`。文档定义主体和关系，Canvas 代码负责主体内部画法，仍使用已选择的完整画风快照。

```json
{
  "version": 1,
  "objects": [
    {"id":"input","box":{"x":0.08,"y":0.3,"width":0.2,"height":0.2}},
    {"id":"rotor","box":{"x":0.42,"y":0.25,"width":0.25,"height":0.3}}
  ],
  "relations": [
    {"id":"feed","source":"input","target":"rotor","source_port":"right","target_port":"left","arrow":true}
  ]
}
```

`code` 在顶层为每个对象注册一次 `object(id, ({ctx,t,w,h,label,...}) => {...})`，在局部 `[0,w] × [0,h]` 像素范围内绘制，不再硬编码对象在全画面中的位置。仍需一个 `scene('shot', ...)` 注册背景，不把信息主体放进背景。运行时将对象按 `layer` 排序、变换和裁切，关系线放在主体后面自动绘制。

- `box`、运动 `dx/dy` 是画布比例，关键帧 `time` 是镜头时长比例；支持 `opacity/scale/easing`。没有关键帧时全程静止，首帧前隐藏；时间严格递增。
- `name` 是描述，不是可信的画面文字提取。实际标签由源码和渲染帧核对；实测文字边界与所属对象 ID 关联。
- 对象矩形不可无声明重叠。有意复合须共享非空 `overlap_group`，文字之间仍需可读；调高层级不会解除碰撞检查。
- 端口支持 `auto/left/right/top/bottom`。路由复用 SceneSpec 原有几何代码，使用当前时刻主体边界、背景文字及讲解员矩形避障，不调用 DrawAI/libavoid。
- `window.__fyObjects()` 返回当前对象边界、版本及每条关系的 `routed/hidden/blocked` 状态。端点隐藏时关系隐藏；无路时隐藏线并报具体关系 ID，不把穿过障碍当成成功。
- 对象/文字边界、独立文字重叠、字幕和讲解员避让接入 `__fyLayout()`。主预检保留稀疏正反序像素检查，并按成片 FPS 扫描有对象文档镜头的布局，包括仅持续一帧的碰撞。入口过渡仍沿用原前 0.25 秒（短镜头的 10%）告警规则。

## 精确修改

沿用完整镜头的 `ReviseShot` 及现有打回意见通道。运维协议前缀为 `SCID_FY_REVISION_V1:`，随后是严格 JSON：

```json
{
  "expect_revision":"当前 scid-fy-data.revision 的 64 位小写哈希",
  "update_objects":[{"id":"rotor","box":{"x":0.45,"y":0.18,"width":0.25,"height":0.3}}],
  "explanation":"将主体向右上移动"
}
```

这里的哈希说明是占位文字，实际请求必须替换为当前版本。普通用户通过 [前端对象工作台](FY_OBJECT_EDITOR.md) 操作，不需要手写协议。

可修改已有对象的 `box/layer/keyframes/overlap_group`，用 `upsert_relations/remove_relations` 修改关系与端口；不支持精确增加/删除画笔、重写对象内部内容或改变旁白。缺失 ID、非法几何/引用、空改动、版本过期、局部时间区间一律明确失败，不退回模型猜测。

内容版本覆盖对象文档、画笔代码、配色、时间轴、输出规格、画风摘要及运行时哈希。重新编译仍保留原画笔、原配色、未编辑对象、旁白和画风来源；运行时或相关上下文变化也不能继续套用旧补丁。HTML 中保存父版本及本次对象/关系的 before/after 差异，不把全部历史重复嵌入每版源码。

精确修改不调用文本模型，只有一次改动机会；仍经源码检查、浏览器预检、原渲染与 VLM 复审。可用时复用原旁白音轨；没有可用音轨时沿原渲染规则处理，不声称声音不变。预检/渲染失败保留原发布产物；复审有未解决任务则返回真实结果供人工核对，不自动整镜重写或伪造通过。

Go worker 在写回事务内复核原镜头、产物、账本、画风和效果；渲染过程中出现竞争编辑时不发布过期结果。内容哈希是版本标识，不是来源签名或任意协作场景的事务系统。

## 兼容与部署

- 旧自由 fy、整章 CLI 与原 SceneSpec 继续可编译/播放。旧 fy 没有对象文档时，精确修改明确报不支持；普通重生成可迁移为新文档，不执行旧源码来猜对象。
- 普通自然语言反馈仍走原有有界模型修复，不能据此承诺所有未指定对象都不变；只有本协议提供受控的数据修改。
- 对象文档只用于无章节 chrome、显式 palette 的单镜 `shot`，内部通过原 HTML `code` 传输，不新增 proto 字段。
- 发布前须协调更新 Python AI、Go worker、API 与前端；未自动重启进程或重新生成已有视频。第二阶段前端实现见 FY_OBJECT_EDITOR.md。

## 限制

包围矩形是保守近似，不是复杂路径/透明像素的精确碰撞体。对象内部未登记构件、背景任意形状、线与线之间的相交不由本阶段通用处理。线条仅支持现有直线/折线候选；`blocked` 可能表示候选集合找不到路线，不证明几何上完全无解。路由逐时刻确定性重算，但可能在不同时间切换拓扑；固定通道与无跳线路径稳定性尚待实现。端点跟随及布局合格都不能证明语义正确或设计优秀，仍需审片。

本阶段不改音色、TTS 服务、真实词锚、定调流程或全片生产策略，不宣称解决声音自然度问题。
