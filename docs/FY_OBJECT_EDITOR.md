# fy 对象工作台

日期：2026-11-10。延续 [对象修订契约](FY_OBJECT_EDITS.md)，只扩展当前审核台，不安装 DrawAI，也不替换引擎。

## 页面入口

展开 fy 分镜，点击「对象编辑」。旧源码没有 `object_document` 和合法 `revision` 时，入口禁用并解释原因；不执行旧代码来推测对象。生成、渲染或审查中的镜头不能提交。

工作台保留现有 antd 暗色、字体、图标与紧凑的信息密度；左侧对象/连线，中间 16:9 真实 Canvas 和差异表，右侧属性；窄屏顺序排列，不引入另一个编辑器框架。

- 对象列表与画布选择使用稳定 ID；可拖动，方向键小幅移动，Shift 加大步长。
- 位置与尺寸按画布百分比编辑，层级为 -100 至 100。叠放组明确表示有意复合，不是自动免除文字可读性检查。
- 新运行时的「绘制角色」可选择内容/背景。背景先于关系线绘制，其实测文字仍避障，不能作为端点；已有连线引用的对象禁选背景，添加/编辑连线也不提供背景端点。修改支持撤销和差异显示，只发送变化的 `role`。旧快照没有 `object_features` 的 `backdrop-v1` 时禁用此项，预览不会偷偷换掉旧内联运行时。
- 可改连线起终点、端口、颜色、线宽、箭头和流动；可添加/删除连线，不能新增/删除画笔对象。
- 时间轴按原 FPS 定位；播放、暂停、修改前/调整后切换共用当前秒数。有稳定对象/关系 ID 的当前帧告警可点击定位；没有 ID 的文字告警不猜目标。没有 TTS、全片后期或讲解员声音预览。
- 撤销/重做仅在本次会话生效，最多保留 60 步。拖动松开后记录一步；不创建服务端版本。关闭前对未提交调整进行确认。
- 保留原关键帧，不在本阶段开放运动轨道或对象内部画法编辑。修改 box 是整体基础位置调整，不是当前时刻打关键帧。

## 预览与提交

`fyPreview.ts` 用 DOMParser 读取不可执行 JSON 标记；严格校验数据，不独立重算服务端版本。预览重放原源码内的运行时和画笔，只替换对象数据；180ms 合并修改后重建离线预览。与正式视频分别显示，不能声称当前 code 必然等于上一版已发布视频的源码。

iframe 只授予 `allow-scripts`，不授予同源、弹窗、表单或顶层导航权限；CSP 禁止网络、外部脚本、资源和子 frame。父页面只接收对应窗口和本次通道的消息，读取运行时的对象边界与布局告警。原脚本不在审核台页面上下文执行。此机制不是 CPU/内存配额，也不替代生成端源码检查或部署隔离。

当前秒数的布局问题会展示并阻止提交；它不代表全时间轴预检、连线语义、美感或正式过审。正式提交仍运行 Python 的完整检查、渲染及 VLM，失败保留原产物，不自动扩大为整镜重写。

提交只发送发生变化的对象字段、完整变更关系和关系删除 ID，以及原 `expect_revision`；不发送整页 HTML、画笔、旁白或虚构的新哈希。协议复用 `POST .../reject`，包含前缀在内按实际字符数检查 2000 上限，超限明确阻止，不截断、自动拆分或退回自然语言。

竞争编辑保护：

1. 工作台打开时冻结基准镜头，收到变化后保留草稿并阻止提交。
2. 点击提交后先回源比对源码、产物 ID、旁白、画面说明、次数及审核账本，并检查非忙碌状态。
3. API/WS 在任务更新锁内检查请求版本与当前持久化快照；格式错误 400，过期/旧格式 409，不消耗重做次数或入队。该快速检查不是完整哈希验真；Python 仍严格验证。
4. worker 沿用最终写回竞争检查，防止渲染期间的变化被覆盖。

## 验证与运行

前端 `npm test`、`npm run build`；Go 定向执行 `go test ./internal/httpapi -run 'Test(CheckFyRevisionBase|FyRevisionErrorMapping)$'`，不触碰运行任务库。

隔离浏览器检查：先启动前端，然后运行：

```powershell
$env:PYTHONPATH='ai;.pylibs'
python scripts/verify-fy-editor.py --fixture .data/previews/fy-object-edit/before.html
```

也可提供其他编译器生成的单镜对象 HTML；脚本需至少两个可见对象。测试使用明确标记的合成任务、拦截全部 API 和 WebSocket；没有真实任务入队、模型/TTS 调用或通过状态造假。对源码数据应用真实 Python 修订校验，并检查 Canvas 非空、对象移动/撤销/对照、拖动、端口、播放、过期提交拦截、旧版本禁用和 390px 窄屏布局。截图与报告留在 `.data/previews/fy-editor/`，不提交测试视频/大文件。

本轮不自动重启现有后端或重做已有视频。上线需协调部署 web、API、worker、AI；旧镜头不自动补对象。定调片、视觉部件库、真实词锚和 TTS 自然度仍未交付。

本轮结果：前端 56 项单元测试通过，生产构建成功（仍有既有的大包体积提示）；Go 版本提前检查/错误映射和 worker 回归通过，未执行依赖运行任务 Redis 的 HTTP 集成用例。生产构建在真实 Chrome 完成上述 16 项浏览器检查，无页面异常；1440px 桌面与 390px 手机截图已人工查看，窄屏工作区内部滚动、底部操作保留在视口内。全部浏览器数据和提交均为隔离测试，不代表用户任务完成了正式渲染/复审。
