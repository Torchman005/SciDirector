# 胶片剪辑动态样片

入口：[film-editing.html](../demos/film-editing.html)。单文件、离线、16:9、10 秒；点击左下播放按钮或拖动时间轴预览。`window.__seek(t)` 接受 0～10 秒的绝对时间，预览播放只负责连续调用它。

## 视觉判断

旧胶片样片把“原片、剪刀、问题/证据/结论”排成三列图标和框，物体之间只有箭头，剪刀合拢却没有剪到胶片。这正是用户所说的“组件很简单”和动画缺少因果关系。

本样片把胶片作为唯一主物件，占据画面中部：

| 时间 | 画面动作 | 要表达的意思 |
| --- | --- | --- |
| 0～2 秒 | 连续胶片落入纸纹舞台，剪刀靠近第一处切口 | 先看到“整段内容” |
| 2～4.2 秒 | 两处切口依次出现，剪刀两次闭合，第一段先分开 | 剪辑是实际发生的动作，不是图标旁的箭头 |
| 4.2～7.2 秒 | 三段胶片错层展开，“问题／证据／结论”依次显现 | 每段承担不同论述职能 |
| 7.2～10 秒 | 画面停在三段结构，主句和手绘下划线收束 | “先找论点，再下剪刀” |

视觉语言是暖纸、深色胶片边、青蓝/芥黄/赭红三个内容场，不用暗色科技渐变、浮动卡片或无意义粒子。右下预留讲解员区域，结论文字放在左侧。图像均为本仓库手写 SVG，不使用参考片帧、不调用生图、不冒充真实视频素材或科学数据。

## 与生成器的距离

这是**手工目标样片**，不是 `SceneSpec` 自动产物，也不说明现有模型已经能生成同等镜头。现有结构化组件能移动图标和画线，但不能把一个具体物件分割成持续存在的三段、让工具作用于切口并保持片段身份。下一阶段应把“对象变化／分割后片段／动作作用点”作为有语义的场景能力接入，而不是只把本文件塞进提示词。人物和道具插画质感仍需要用户提供或另行授权制作原创素材。

本轮只做离线源码与契约校验。当前内置浏览器禁止打开本地 `file://` 页面，未用其他浏览器路径绕开该限制，因此不把此样片声称为已完成视觉验收；请以实际观看反馈决定是否沿这条美术方向继续。
