# 视频质量改进（2026-10）

## 审核与定点修订

结构化场景首稿仍返回 SceneSpec。修订改用 SceneRevision：`upsert` 替换/新增完整元素，
`remove` 删除元素，未提及的元素保持原位及原内容。重复 ID、删除不存在对象、空场景、
没有实际元素变化的修订直接拒绝，并共用原来的生成内修复预算。没有增加无限重试。

审核读取当前渲染版本的元素清单，能用稳定的 `#id` 指明修改位置，并核对真实字号、
区域与关键帧。抽帧仍是最终依据；声明“已修复”不会关闭问题。
复审补抽帧由 320px 提升至 1024px，避免文字修复证据自身不可读；像素比较仍使用 320px。

通过阈值及科学准确性底线保持不变。只有画面证据证明满足原验收条件才关闭修复任务。
未解决的问题依然进入人工复核，不会以提高通过率为由伪造通过。

## 二次元科学剧场

新建任务可选择二次元科学剧场或严谨图解。角色在开场、转折、总结穿插，数学镜头仍走 Manim。
结构化渲染器新增原创赛璐璐讲解员（表情、手势、呼吸、眨眼）、轨迹/关系描线、几何缩放和阻尼缓动。
所有运动由绝对时间决定，支持倒序、重复与分块渲染。文字与数据不允许任意缩放旋转。

无模型调用的参考镜头：`python scripts/render-anime-demo.py --render`（需 PYTHONPATH=ai、Chromium、ffmpeg）。
这是固定组件的示例，不代表任意脚本已达到同样质量；生成结果仍走原科学审核链路。
