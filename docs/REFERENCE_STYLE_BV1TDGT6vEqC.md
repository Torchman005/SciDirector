## 最重要的发现

可以把目标准确描述为：**奶油色纸纹舞台、日式人物多姿态立绘、复古插画道具和围绕旁白的素材演出**。

大部分取样画面采用简洁且一致的米色背景：细竖线、低对比纹理，以及底部具有透视形状的地毯/地面。它提供色彩基底和轻微空间感，画面并不依靠复杂室内布景。角色、家具和道具本身的绘制质量承担了大部分视觉丰富度。

在检查的连续片段中，背景基本固定，明显变化主要来自前景素材的位移、缩放、交叉淡化和人物姿态切换。因此不应把“增加整屏运镜”作为首要改造方向；先保证素材、构图与叙事动作成立。

## 场景与人物质感来自哪里

1. **统一材质。** 米白/暖灰基底，偏低饱和的粉、棕、黄、紫作为前景色；道具带纸片边缘或浅色描边，并有绘制在素材内部的细节与阴影。
2. **人物比例与细节。** 发丝、服装褶皱、面部、手势和姿态属于立绘本身的美术质量；代码组件的几何轮廓无法直接补出这些细节。
3. **状态承担叙事。** 坐着、思考、操作电脑、推箱子等是不同完整姿态，不只是待机形象循环摆动。采样中的姿态切换可以用多张透明立绘和交叉淡化复现；这不等于已确定原片的制作方式。
4. **清楚的前景层级。** 人物与道具有足够间隔和轮廓对比，背景弱化；通常一组重点对象承担一句话或一个节拍。
5. **稳定的画面锚点。** 底部字幕和章节条基本固定；前景运动不拖动字幕，内容替换时仍能保持观看位置。

## 对 SciDirector 的具体影响

当前代码核对结果：

- `ai/scidirector_ai/scene.py` 的 `Element.kind` 包含文字、卡片、几何、图表、图标和历史人物组件，**没有通用受信任图片素材层**。
- `SceneSpec.background` 支持纯色、渐变、网格、暗角、噪点和扫描线，尚没有与这个参考对应的浅色纸纹舞台。
- 现有独立讲解员层能导入 Live2D 或四状态立绘，但这不等同于每个分镜都能安排家具、道具和叙事动作立绘。
- 因此核心缺口是美术素材与分镜编排能力。只增加渐变、弹跳或提示词，无法得到参考片中的角色与道具细节。

建议按以下顺序实现；这是一份实施输入，不是现有能力声明：

1. **受信任素材层。** 导入原创/用户提供的 PNG、WebP/JPEG，服务端签发 ID；生成模型只能引用素材目录中的 ID。角色透明图保留 alpha，按原始比例显示。图片边界、阴影与实际遮挡分开计算，不允许模型随意加载文件或外部 URL。
2. **纸纹舞台。** 新增浅色风格与背景，配套深色文字、低对比纹理、地面透视和柔和接触阴影，统一 HTML 与其他渲染器的样式契约。场景纹理不应干扰科学图表。
3. **可编排的人物与道具。** 区分持续讲解员和镜头叙事素材；按旁白节拍选择姿态、显隐、位置与关注对象。依照用户已有要求，持续 Live2D 仍叠在右下角，保留局部避让，不为它挤出整列区域。
4. **克制且可验证的运动。** 先做好素材入场、姿态交叉淡化、主次缩放和成组平移，再增加必要的轻微运镜。运动必须可重复 seek，字幕独立，图解关系保持准确。明确标注有意的交叉淡化，避免审核把过渡叠加一概判错，同时保留稳定画面的遮挡门禁。
5. **按叙事需要准备素材。** 用户目前要求暂不生图。可以先实现导入和编排，沿用已有模型/立绘；后续美术资源应围绕明确的动作需求准备。数学公式、数据和结构关系继续由确定性图形渲染，不能让插画替代科学事实。

## 后续视觉验收建议

- 做一段 20–30 秒的固定样片，至少包括“提出问题 → 对象对比 → 人物动作解释”的三个节拍；先验收整体美术，再扩大自动生产。
- 对照实际参考画面的材质、人物细节、对象主次和动作含义，避免把通过静态边界检测当成视觉质量已达标。
- 复核稳定帧及转场中点：字幕完整、角色不遮挡关键信息、浅色物体轮廓可辨、前景不会随意穿插。
- 如只完成背景或运动代码而尚未提供足够质量的角色/道具素材，应明确报告缺口，不能宣称已达到参考质感。
