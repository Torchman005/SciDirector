# SciDirector AI

Python 服务与独立章节视频工作流。完整项目说明见
[SciDirector](https://github.com/Torchman005/SciDirector)。

`scripts/make-chapter.py` 支持 SVG 和可选的 fy Canvas 试验；使用说明见仓库
`docs/CHAPTER_MODE.md`。渲染需要 Playwright/Chromium 和 FFmpeg。

项目代码采用 MIT。`scidirector_ai/chapter/fy_vendor/` 内固定版本的
fy-code-animation 组件及读取器适用该目录保留的原作者许可与来源说明，
不适用项目 MIT 许可。外部 341 画风库、字体和音视频不随本包分发。
